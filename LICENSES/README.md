# LICENSES — полные тексты лицензий сторонних компонентов

Заведён 22.08.2026 (задача Б19). Здесь лежат **дословные** тексты лицензий тех
компонентов, которые попадают в поставку вместе с нашим кодом. Перечень
компонентов, версий и источников — `../THIRD_PARTY_NOTICES.md`.

**Откуда взяты тексты.** Каждый файл скопирован побайтово из самого дистрибутива,
установленного в окружении, а не переписан и не скачан «похожий»:

| Файл | Источник |
|---|---|
| `GPL-3.0.txt` | `resdata-6.3.3.dist-info/licenses/COPYING` — канонический текст GPLv3 от FSF |
| `resdata-6.3.3-GPL-3.0.txt` | `resdata-6.3.3.dist-info/licenses/LICENSE` — копия, приложенная самим `resdata` |
| `openpyxl-3.1.5-MIT.txt` | `openpyxl-3.1.5.tar.gz` → `LICENCE.rst` (в колесе текста нет) |
| остальные `<пакет>-<версия>-<лицензия>.txt` | `<пакет>.dist-info/licenses/…` соответствующего дистрибутива |

Имя файла несёт версию намеренно: лицензия — свойство конкретной версии, а не
названия пакета. Обновили пин — обновляется и текст; это закреплено тестом
(`tests/test_packaging.py`).

Перевод строки у этих файлов git не нормализует (`.gitattributes`,
`LICENSES/*.txt -text`): «keep intact all notices» плохо сочетается с тем, чтобы
мы по дороге меняли им байты. Проверено — блобы в индексе совпадают с
дистрибутивами побайтово.

**Чего здесь пока нет.** Лицензионных файлов Ubuntu-пакетов, попавших в образ, —
в первую очередь самих OPM (`libopm-simulators-bin` и его зависимостей),
`mpi-default-bin` и системного `python3`. Они лежат в образе в
`/usr/share/doc/<пакет>/copyright`, и снять их можно только из собранного образа;
Docker на машине, где собирался этот каталог, нет. Команда и причина —
`../BLOCKED.md`, п. 7. Текст GPLv3, под которым идут OPM-компоненты, приложен
здесь в любом случае: он один и тот же документ.

`LICENSE` в корне нет — вопрос владельца, `../BLOCKED.md`, п. 8.
