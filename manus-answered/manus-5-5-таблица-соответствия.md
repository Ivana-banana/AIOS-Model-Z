## Допустимые значения для поля «Статус»

| Статус | Значение |
|---|---|
| `реализовано` | Ограничение распознано, применено в расчёте и подтверждено тестом/прогоном |
| `реализовано частично` | Проверена только часть области действия, периода или режима |
| `не реализовано` | В конфигурации/коде отсутствует реализация |
| `не проверяется` | Реализация возможна, но текущий стенд не имеет нужных данных или модели |
| `не найдено` | В исходном ТЗ или входных данных нет нужного значения/определения |
| `требует уточнения` | Возможны две или более равноправные трактовки |

## Минимальная запись доказательства

Для каждого ограничения сохраните: исходную цитату; нормализованную формулу; конфигурацию или коммит, который её реализует; входной тестовый пример; команду запуска; ожидаемый результат; фактический результат; единицу измерения; период и идентификатор скважины/группы; лог или файл отчёта. Утверждение «нарушений нет» без фактического максимума/минимума/суммы и без ссылки на артефакт считается недостаточным.

## Формулы для сверки

| Случай | Формула |
|---|---|
| Объектный пик | `max_t Σ_w q_{w,t} ≤ Qmax` |
| Скважинный пик | `max_t q_{w,t} ≤ Qw,max` для каждой `w` |
| Среднее за период | `(Σ_t q_t·days_t)/(Σ_t days_t) ≤ Qavg` |
| Календарный годовой объём | `Σ_{t∈year} q_t·days_t ≤ Vyear` |
| Компенсация отбора | `Qinj_t / Qprod_t ≥ C` или формула из ТЗ |
| Внешняя вода | `Qexternal_t ≤ Qexternal,max,t` |
| Число активных скважин | `Σ_w 1(x_{w,t}=OPEN) ≤ Nmax` |
| Окно ремонта | `x_{w,t}=SHUT` для `t∈[D1,D2]` |

**Важно:** формулу компенсации, поток и число дней нельзя выбирать по умолчанию, если они не определены в ТЗ. В таком случае значение или семантика — **не найдено**.
