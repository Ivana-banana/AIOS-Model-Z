# Таблица соответствия условий кейса

Заполняется в день выдачи валидационного кейса, одна строка на **атомарную**
формулировку из ТЗ. Основа — шаблон из ответа Manus 5-5
(`manus-answered/manus-5-5-Шаблон таблицы соответствия ограничений.md`), разбор —
`docs/manus/round5.md`. Порядок работы и цена ошибок —
`docs/validation-case-checklist.md`.

Пока таблица пуста: кейса нет. Примеры внизу заполнены нашими настоящими ключами,
чтобы под таймером не вспоминать их имена.

**Правило.** Значение, единица, период или способ проверки отсутствуют — пишем
**«не найдено»**, а не умолчание. Строка «нарушений нет» без фактического
максимума, периода и ссылки на артефакт не считается проверкой.

## Словарь статусов

| Статус | Смысл |
|---|---|
| `реализовано` | условие распознано, применено в расчёте и подтверждено тестом или прогоном |
| `реализовано частично` | проверена часть области действия, периода или режима |
| `не реализовано` | ключа или ветки нет |
| `не выражаем` | расписанием не выражается в принципе; идёт в отчёт оговоркой |
| `не найдено` | в ТЗ или входных данных нет значения либо определения |
| `требует уточнения` | две равноправные трактовки; до ответа берём строгую |

## Формулы сверки

| Случай | Формула |
|---|---|
| объектный пик | `max_t Σ_w q_{w,t} ≤ Qmax` |
| скважинный пик | `max_t q_{w,t} ≤ Q_{w,max}` для каждой скважины |
| среднее за период | `(Σ_t q_t · days_t) / Σ_t days_t ≤ Qavg` |
| календарный годовой объём | `Σ_{t∈year} q_t · days_t ≤ Vyear` |
| компенсация отбора | `Qinj_t / Qprod_t ≤ water_tolerance` |
| сторонняя вода | `Qinj_t ≤ Qproduced_water_t + max_external_water_m3_per_day` |
| число действующих скважин | `Σ_w 1(WLPR_{w,t} > 0 ∨ WWIR_{w,t} > 0) ≤ Nmax` |
| окно ремонта | `SHUT` для `t ∈ [D1, D2]` |

Число суток берётся из календаря выгрузки (`aios.balance.days_of`), а не из
среднего месяца: на немесячном шаге оно даёт 246 суток вместо 730 и режет
закачку втрое сильнее, чем следует (`validation-case` §6).

**Формулу компенсации, поток и число дней нельзя брать умолчанием, если они не
определены в ТЗ.** В этом случае статус строки — «не найдено».
