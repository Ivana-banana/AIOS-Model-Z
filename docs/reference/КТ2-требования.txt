Расчётное значение ЧДД на базовом сценарии

Часто спрашивают, какое ЧДД получается на базовом сценарии — то есть на управляющих последовательностях, уже заданных в предоставленных моделях, без оптимизации со стороны команд.

Публикуем файлы с подробным расчётом по Model Y и Model Z. Расчёт по каждой модели выполнен в двух симуляторах — тНавигатор и OPM Flow.

Итоговые значения между симуляторами немного расходятся — это связано с особенностями самих симуляторов, а не с ошибкой в методике расчёта. При валидации ваших решений это расхождение будет учитываться (допуск на уровне погрешности между симуляторами).
