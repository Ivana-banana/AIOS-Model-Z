Идите сверху вниз. Если ожидаемая строка не получена, **не отправляйте пакет**:
остановитесь и разберите расхождение. Все команды выполняются из корня проекта.

## 0. Проверить, какой кейс запрошен

Этот паспорт фиксирует пакет, посчитанный на **Модели Z**. Если организаторы уже
выдали валидационный кейс по п. 4.3 ТЗ и запрашивают результат на нём, **не
отправляйте** указанные ниже `matched-0995`, ЧДД и тег: они не определяют место в
рейтинге. Сначала выполните полный контур на новом деке и нормативах, затем заново
выпустите согласованные файл, число, контрольные суммы, документы и тег.

намеренно не отслеживается git (5 МБ на прогон), поэтому пересчитать заявленное
число может только машина, где выгрузка лежит. Машинный след её расчёта

**Что это значит для дня отправки.** Если отправляет машина с выгрузками —
проходить должны все семь. Если выгрузок нет, пятый пункт **обязан** выдать
именно это сообщение, а не молчание: «пересчитывать нечего» — законный исход,
«число совпало» без выгрузки было бы ложью.

## 4. Если проверка не сошлась

| Случай | Действие |
|---|---|
| ЧДД отличается | не отправлять; в **отдельной чистой копии** `submit-2026-09-02` выполнить шесть команд `docs/submission.md`, раздел 3; итоговый файл вернуть в текущий `main` и здесь повторить весь раздел 1 |
| Нет `runs/` | это воспроизводимый каталог под `.gitignore`; получить его шестью командами `docs/submission.md`, раздел 3, не искать в git |
| Нет OPM Flow | использовать Docker-путь из `docs/setup-simulator.md`; если он тоже недоступен, остановиться и сообщить `ЧДД не воспроизведён: симулятор недоступен` |

## 5. В день отправки запрещено

Не пересобирать заявку, не менять `config.toml`, не улучшать число. Любое
изменение после проверки отменяет её результат: повторите раздел 1 целиком.
