# Паспорт дня отправки

Идите сверху вниз. Если ожидаемая строка не получена, **не отправляйте пакет**:
остановитесь и разберите расхождение. Все команды выполняются из корня проекта.

## 0. Проверить, какой кейс запрошен

Этот паспорт фиксирует пакет, посчитанный на **Модели Z**. Если организаторы уже
выдали валидационный кейс по п. 4.3 ТЗ и запрашивают результат на нём, **не
отправляйте** указанные ниже `matched-0995`, ЧДД и тег: они не определяют место в
рейтинге. Сначала выполните полный контур на новом деке и нормативах, затем заново
выпустите согласованные файл, число, контрольные суммы, документы и тег.

## 1. Проверить перед отправкой

| Команда | Ожидаемый итог |
|---|---|
| `git status --short --branch` | только `## main...origin/main`, без других строк |
| `python -m pytest -q` | `0 failed, 0 errors`; допустимы только `passed` и `skipped`. **Но пропуск не бесплатен:** тесты, сверяющие заявляемое число, пропускаются, когда в `runs/` нет выгрузок, — на машине сборки это значит, что заявка не пересчитана, и увидеть это надо по пункту 6 `check_package.py`, а не по зелёному прогону |
| `python -m ruff check .` | `All checks passed!` |
| `python scripts/check_release_tag.py` | `[ГОТОВО]`, тег и его инструкция воспроизведения совпадают с `docs/submission.md` |
| `python scripts/check_package.py` | все 10 строк `[ГОТОВО]`, последняя строка `пакет готов` |
| `python scripts/check_submission.py runs/matched-0995/wells_schedule.inc` | последняя строка `файл пригоден к отправке` |

## 4. Если проверка не сошлась

| Случай | Действие |
|---|---|
| ЧДД отличается | не отправлять; в **отдельной чистой копии** `submit-2026-08-24.1` выполнить шесть команд `docs/submission.md`, раздел 3; итоговый файл вернуть в текущий `main` и здесь повторить весь раздел 1 |
| Нет `runs/` | это воспроизводимый каталог под `.gitignore`; получить его шестью командами `docs/submission.md`, раздел 3, не искать в git |
| Нет OPM Flow | использовать Docker-путь из `docs/setup-simulator.md`; если он тоже недоступен, остановиться и сообщить `ЧДД не воспроизведён: симулятор недоступен` |
