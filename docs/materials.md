# Материалы, ссылки, ремоуты

Сами файлы организаторов лежат в репозитории — `materials/`, там же их опись и
инструкции по распаковке (`materials/README.md`). Здесь то, что файлами не
является: внешние ссылки и настройка репозиториев.

## Что где

| Нужно | Где |
|---|---|
| Архивы, презентации, методики | `materials/` |
| Опись материалов и распаковка | `materials/README.md` |
| Расшифровки записей встреч | `docs/method/transcripts/` |
| Слайды лекции 11.08 (ML), с цитатами литературы — точнее аудио | `docs/method/lecture-2-ml.txt` |
| Слайды лекции 12.08 (разработка месторождений) — точнее аудио | `docs/method/lecture-3-reservoir.txt` |
| Разбор регламента из лекции 10.08 (только аудио, слайдов нет) | `docs/method/lecture-1-regulations.md` |
| Ответы организаторов на вопросы команд | `docs/method/qa-organisers.md` |
| Отличия двух методик ЧДД | `docs/method/diff.md` |
| Скрипт выгрузки организаторов | `docs/method/organisers-export-script_1.py` |
| Скриншоты постов из канала | `docs/screenshots/` |

Записи встреч (458, 526 и 801 МБ) в репозиторий не помещаются: у GitHub жёсткий
предел 100 МБ на файл, а Git LFS на бесплатном тарифе даёт 1 ГБ на всё. Они в
облаке организаторов, их содержимое — в расшифровках.

## Симуляторы и открытые данные

Ответ организаторов на вопрос команды: гидродинамику нужно считать самим,
запустив симулятор на выданной модели.

- **tNavigator** — при наличии лицензии у участников (модель сгенерирована в нём,
  v25.1-3286).
- **OPM Flow** — https://opm-project.org/?page_id=19 — наш выбор,
  см. `docs/setup-simulator.md`.
- **MRST** — https://www.sintef.no/projectweb/mrst/.

Открытые датасеты: OPM (https://opm-project.org/?page_id=559),
Equinor Volve 2008–2016 (https://www.equinor.com/energy/volve-data-sharing),
ORSD (IBM Data Platform), Reservoir Models Dataset (https://hw.tpu.ru/en/dataset/).
